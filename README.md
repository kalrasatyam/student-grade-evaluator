# Student Grade Evaluator

A simple C++ console program that takes a student's marks and attendance, calculates their average grade, and checks eligibility for semester exams and scholarships using conditional statements.

## Features
- Input validation to catch negative marks or numbers above 100
- Grade assignment (A through F) based on average score
- Subject pass/fail check (minimum passing score of 40)
- Exam eligibility check (requires at least 75% attendance)
- Merit scholarship qualification logic

## How to Run

1. Open Terminal in the project directory.
2. Compile the source file:
   g++ main.cpp -o main
3. Run the executable:
   ./main

## Built With
- C++
- Basic control flow (`if`, `else if`, `else`)
- Standard I/O (`cin`, `cout`, `getline`)
